## Что такое Topitor?

**Topitor** — это децентрализованный мессенджер, работающий полностью **на технологиях P2P, Tor и BitTorrent**. Название как раз и является сочетанием этих технологий: **To**r + **P**2**P** + **Tor**rent.

Серверной инфраструктуры нет вообще: данные передаются напрямую между устройствами. Весь сервис **абсолютно бесплатный** — никаких подписок, рекламы или платных функций нет и не планировалось.

## Платформы

Релизные сборки доступны только для двух операционных систем:

| Платформа | Формат файла | Примечание |
| :--- | :--- | :--- |
| **Windows** | `.zip` | Поддерживаются Windows 10 и Windows 11. |
| **Android** | `.apk` | Для Android 8.0 и выше. |

> **Ограничения:** Сборки для macOS и Linux отсутствуют.

## Установка

### Windows
1. Скачайте в Релизах файл zip для Windows (Topitor-Windows.zip).
2. Запустите его. **Внимание:** из-за отсутствия цифровой подписи Windows SmartScreen может показать предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае», чтобы продолжить.
3. Следуйте инструкциям мастера установки.

### Android
1. Скачайте файл `.apk`.
2. Разрешите установку из неизвестных источников в настройках телефона (если система попросит).
3. Откройте файл и завершите установку.

## Возможности (фактический список)

Приложение включает в себя следующий набор функций:

- **Общение:** Личные чаты, групповые чаты, каналы, звонки (аудио) и видеозвонки.
- **Медиа:** Отправка фото, видео, GIF-анимаций, стикеров, голосовых сообщений и «кружков» (видеосообщений).
- **Файлы:** Поддерживается загрузка файлов **любого типа**. Жестких лимитов нет (рекомендуется не превышать 100 МБ на один файл).
- **Социальные функции:** Поиск друзей, карточка профиля, статус, описание, избранное, истории, приглашение («позвать»).
- **Дополнительно:** Телевидение (ТВ), радио, заметки, кошелёк, геопозиция, одноразовые фото, кастомные аватарки, протоколы чата и прочие мелкие функции.

## Технические детали и ограничения

- **Архитектура:** Полностью децентрализованная (P2P). Сообщения, звонки и файлы передаются напрямую между устройствами через протокол BitTorrent и сеть Tor для обеспечения анонимности и обхода блокировок. Центральные серверы для хранения или маршрутизации трафика не используются.
- **Стоимость:** Абсолютно бесплатно. Подписок, рекламы и реальной оплаты нет.
- **Технологический стек:** Не раскрывается (закрытый проект).
- **Подписи / сертификаты:** Отсутствуют (проверка разработчика не выполняется).
